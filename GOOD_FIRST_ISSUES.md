# Good first issues

These are ideas for future contributions. They are intentionally not part of the starter MVP.

1. Add a dark mode toggle.
2. Let owners add a photo to a vehicle.
3. Add vehicle search by make, model, or registration.
4. Add an explicit sort control for maintenance history.
5. Show total maintenance cost for a vehicle.
6. Add a yearly maintenance cost summary.
7. Highlight an upcoming service date.
8. Add an overdue-service warning.
9. Track fuel fill-ups and efficiency.
10. Track insurance expiry dates.
11. Attach service bills or other documents.
12. Export maintenance history as CSV.
13. Add simple maintenance cost charts.
14. Improve the layout for small mobile screens.
15. Add opt-in service reminders.
